# Assignment #4: Forms and Validation

A set of five HTML pages that practise building forms and validating them in the browser, with plain HTML5 and Bootstrap 5.3. There is no server: forms are only checked on the client and no data is sent anywhere.

## Tasks

- **Task 0** — Simple contact form in plain HTML (no Bootstrap, no JavaScript).
- **Task 1** — Contact form with HTML5 validation (`required`, `type="email"`, `minlength`, `maxlength`, `pattern`).
- **Task 2** — Contact form styled with Bootstrap and the Bootstrap grid.
- **Task 3** — Contact form with Bootstrap validation styles (`is-valid`, `is-invalid`, `valid-feedback`, `invalid-feedback`). A short inline script updates the field states.
- **Task 4** — Responsive registration form with Bootstrap, HTML5 validation, password confirmation check and a Reset button (`js/registration.js`).

## Run locally

No installation is needed. Open `index.html` in a web browser. Bootstrap is loaded from a CDN, so an internet connection is required for Tasks 2–4.
